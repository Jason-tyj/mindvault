# 10-Logs · 日志

## Daily/

日常记录，文件名格式 `YYYY-MM-DD.md`，无 YAML frontmatter，以 `##` 标题分节。
当前最早记录：2026-05-05；内容为近期工作日志，口语化语气。

**建档与写入真源**：[[Daily/instruction|Daily/instruction]]（2026-11-06 Jason 定；charter v1.21）。

- 每天**第一次**创建当日文件时，固定五个一级节、顺序不可改：`## 今日日程` → `## 待办清理` → `## 运动` → `## 随手记` → `## 工作记录`（样例 [[Daily/2026-11-06]]）。
- 专项（系统备忘、Inbox 整理、飞书总结、情报日更、周巡检等）写在 `## 工作记录` 下用 `###`；不要另开 `## 系统`。
- 谁先触发谁建档；禁止只建半截 `## 工作记录`。任意 agent / 定时任务均适用。

典型用途：
- 当日待办与日程记录
- 会议纪要、培训产出（如讲话稿草稿）
- 工具配置与学习记录
- 运动与随手记（一级节）

跨会话查找当日上下文时，优先读取对应日期的日记文件。

## Monthly/

月度日志汇总，文件名格式 `YYYY-MM.md`，由当月 Daily 日记总结而来。
首篇为 [[10-Logs/Monthly/2026-05|2026-05.md]]，结构示例：月度概览 / 分主题主线（AI/合规/研究/合作/运营/个人）/ 小结与下月衔接。

跨月回顾、年度复盘、对外汇报素材整理时优先读取 Monthly 文件，再下钻到 Daily。

## wiki-log

[[wiki-log]] 是库级只追加变更日志，与 Daily 分工不同：Daily 仍是人和日程的事件总线，每次写库必须在当日 Daily「## 工作记录」记一笔（现行硬规则不变）；wiki-log 只记录这次改了哪些库内页面、由谁、因为什么。Daily 那一笔可写摘要并链到本日志。

- 文件：[[wiki-log]]（`wiki-log.md`），只追加，不改旧条。
- 格式：

```
## [YYYY-MM-DD] <类型> | <bot> | <一句话摘要>
- 改动：[[wiki链接]], [[wiki链接]]
- 原因：一句
```

- 类型限定：`ingest` / `query` / `lint` / `fix` / `rule`。
- 规则真源见根目录 [[CLAUDE]]「稳定页、引用与变更传播」。质检师周巡检应核对 Daily 写库记录与 wiki-log 是否对应。
