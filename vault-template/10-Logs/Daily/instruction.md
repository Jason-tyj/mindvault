# Daily · 日记

文件名 `YYYY-MM-DD.md`，无 YAML frontmatter，以 `##` 标题分节，口语化。最早记录 2026-05-05。

- 记当日日程、待办、会议纪要、培训产出、工具配置与学习
- 当日产出的草稿（讲话稿、邮件初稿）也记在当天日记里
- 跨会话查当日上下文优先读对应日期文件；月生成后 Daily 保留原地不归档

## 写入约定

- **不写日期行 / 星期行**：日记文件直接以 `##` 分节开头，日期由文件名 `YYYY-MM-DD.md` 承载，正文不重复日期标题（不写 H1）。
- **不设独立 `index.md`**：`Daily/` 属特殊处理，新日记统一登记到库级 [[../index|10-Logs/index]]，`Daily/` 下不新建 `index.md`。
- **路径一律 wiki 链接**：提及 vault 内笔记/目录时用 `[[相对或库内路径|显示名]]`，禁止只写反引号裸路径（否则 Daily 不可点跳转）。

## 建档骨架（2026-11-06 Jason 定；以后每天第一次创建日志时按此结构）

真源样例：[[2026-11-06]]。文件不存在、需要新建时，**只创建下列五个一级节**（可空），顺序固定，勿增减、勿改名、勿调序：

```md
## 今日日程

## 待办清理

## 运动

## 随手记

## 工作记录
```

补充规则：

- **专项内容进「工作记录」**：情报日更、Vault 写入、Inbox 整理、飞书工作区总结、系统备忘等，一律写在 `## 工作记录` 下；需要分组时用 `###`（如 `### 系统`、`### 00-Inbox 每日整理`、`### 🦞 飞书工作区总结 · YYYY-MM-DD`），**不要**再开并列的 `## 系统`。
- **运动 / 随手记是一级节**：跑步与体感写 `## 运动`；零散想法写 `## 随手记`；不要把运动塞进工作记录。
- **已有文件只追加**：当日文件已存在时，往对应节追加内容，不要为了「补齐骨架」重排历史正文（除非 owner 明确要求改某天）。
- **谁先触发谁建档**：任一 bot 当日首次写入 Daily 时，若文件不存在，必须按上述完整骨架新建，再写入自己的段落；禁止只建 `## 工作记录` 半截文件。
